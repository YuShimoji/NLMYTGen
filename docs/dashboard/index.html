Boundary Check

This cockpit does not start real `codex exec`, does not add `subprocess.run`, does not pipe stdin, does not create a runtime worker loop, does not send external notifications, and does not authorize `.agent` runtime artifacts. G-28, G-27, GUI, YMM4, render, rights, production, publishing, ClipPipeGen, Newsroom, RSS, OPML, Inoreader, and NotebookLM work remain outside this slice.
