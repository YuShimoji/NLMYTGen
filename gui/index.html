NLMYTGen

上のタブで画面を切り替えると、左の手順はそのタブの入り口に合わせて移動します。

意思決定・手動確認が必要なタイミング

ウィザードの範囲：S-3（台本→CSV）と S-6b（IR 検証・演出適用）まで。S-4/S-5（YMM4 取込・読み上げ・字幕直し）、S-7〜S-9（通し・サムネ・投稿）は本 GUI の外です。詳細は「操作ガイド」→ docs/GUI_MINIMUM_PATH.md。

機械が保証する範囲：IR 語彙・row-range・palette 整合・patch 時の failure class 検出。ここで止まったらログのコード名が一次手掛かりです。

必ず人が見るタイミング：YMM4 取込後の読み上げ・字幕の最終見た目（ツールの表示幅は近似）。表情ラベルの見え方の妥当性、背景・テンポ・音量の創作判断、通しプレビュー、サムネ・公開判断。

頻度を抑える運用：増分変更のたびに visual proof を求めない方針です。初回 E2E と最終制作物の確認を優先し、同じ種類の失敗の繰り返し確認は避けます（docs/OPERATOR_WORKFLOW.md「検証の境界」参照）。

TIMELINE_ROUTE_MISS / SE_WRITE_ROUTE_UNSUPPORTED：多くは「その ymmp に経路が無い」というサンプル・テンプレ依存です。創作判断というより、別テンプレで再測定するか feature を見直す設計判断が先にあります。
