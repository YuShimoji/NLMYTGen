# Next Order

The next revenue-facing action is a private delivery test with one real
NotebookLM transcript supplied by the customer or operator.

## Proposed Step

Sell or run one pilot package:

- Input: one customer-approved NotebookLM transcript.
- Output: YMM4 CSV, speaker map, cue packet, optional diagram packet.
- Review: customer or editor imports the CSV into YMM4 and returns concrete
  import/readability issues.
- Revision: one included correction pass for speaker mapping, wrapping, or
  obvious parse mistakes.

## What To Learn

- Does the CSV import cleanly into the customer's YMM4 environment?
- How much transcript cleanup is needed before conversion?
- Does the cue packet reduce production prep time?
- What price point is acceptable for one transcript package?

## Automation Rule

Automate only after pilot evidence shows the repeated work. Do not reopen live
RSS, source scraping, OAuth, upload, payment, or common-foundation runner work
before this private delivery loop produces evidence.
