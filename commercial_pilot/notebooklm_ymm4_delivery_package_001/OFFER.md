# Offer

## Target Buyer

Creators, editors, and small content teams who already use NotebookLM for audio
overview or transcript drafting and want a faster path into YMM4 manual
production.

## Solved Problem

NotebookLM output is useful as source text, but it is not immediately ready for
YMM4 script import or production planning. This offer converts one transcript
into a YMM4 import CSV plus a cue packet that a human editor can act on.

## Deliverable

- YMM4 script-import CSV.
- Speaker map used for the conversion.
- Cue packet for background, support material, and production preparation.
- Optional diagram brief packet when the transcript benefits from figures.
- Acceptance checklist and limitation notes.

## Customer Input Requirements

- One NotebookLM audio overview transcript or equivalent dialogue transcript.
- Desired YMM4 character names for each speaker.
- Any known forbidden phrases, naming preferences, or tone requirements.
- Optional: requested cue density, target video length, and whether diagram
  planning is needed.

## Price Range

Initial pilot price: `¥5,000〜¥20,000 / 1 transcript package`.

The final price moves with transcript length, speaker count, cue density,
required cleanup, and whether a diagram brief is included.

## Delivery Scope

This is a manual delivery service. The operator receives cleaned production
inputs and imports them into YMM4 manually. One light revision pass can be
included for the paid pilot when the transcript scope is agreed upfront.

## Excluded Work

- YouTube upload or channel operation.
- OAuth, API key, payment, or account setup.
- Rights/legal acceptance of source material.
- NotebookLM source selection or live RSS/news gathering.
- Finished thumbnails, final rendered video, or YMM4 visual guarantee.
- Automatic asset download or media sourcing.

## Acceptance Criteria

- CSV imports into YMM4's script import path without obvious structure errors.
- Speaker names map to the requested YMM4 character names.
- The cue packet is usable for manual production preparation.
- The human reviewer can identify any remaining judgement items quickly.

## Manual Steps

1. Customer supplies transcript and speaker mapping.
2. Operator generates CSV and cue packet.
3. Human checks speaker continuity, line wrapping, and parse mistakes.
4. Customer or editor imports the CSV into YMM4.
5. Optional paid pilot revision fixes concrete import or readability issues.

## Rights And Risk Note

The customer remains responsible for source rights, third-party media rights,
publication claims, and final visual acceptance. This package does not assert
that the content is publishable.

## Repeat Path

After one successful private delivery test, sell a repeatable per-transcript
package. Automation should be limited to steps proven by pilot evidence.
