# Pattern Benchmark

| pattern | novice support | action clarity | verdict |
|---|---:|---:|---|
| Dashboard / status board | 3 | 2 | Good for at-a-glance monitoring, weak for novice decision discovery. |
| Start page / service entry | 5 | 4 | Strong at explaining purpose and first action, but needs a decision mechanism. |
| Task list / checklist | 3 | 3 | Useful for multi-step completion, but this slice is one decision with optional evidence. |
| Command center / cockpit | 2 | 3 | Power-user friendly but repeats the current weakness: internal state can dominate. |
| Wizard / step-by-step decision flow | 5 | 5 | Best fit for helping a novice discover the correct next action while deferring evidence. |
| Card board / kanban-like review surface | 3 | 3 | Scannable but risks making all options look equal and board-like. |

## Candidate Comparison

| candidate | status | score | key reason |
|---|---|---:|---|
| Candidate A: start page plus decision board | runner_up | 34 | Best introductory frame and low-friction first screen. |
| Candidate B: guided decision flow | selected | 41 | Turns the review into a small sequence of situation checks and recommends one next action. |
| Candidate C: novice-friendly command center | rejected | 27 | Preserves cockpit continuity and compact status visibility. |
